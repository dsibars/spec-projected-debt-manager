# Skill: React UI

## Description
Provides the ability to project domain presentation and logic into React components and hooks.

## Constraints
- Functional components only.
- Use standard hooks (`useState`, `useEffect`, `useMemo`, `useCallback`).
- No external state management libraries (use React Context or simple state lifting).
- Use Tailwind CSS for styling (see `@shared/skills/ui/tailwind`).
- All components must be accessible (ARIA labels, keyboard navigation).
- **Separation of Concerns**: Keep presentation components (UI) separate from logic (Hooks).
- **Pattern Compliance**: Follow patterns defined in `@shared/skills/ui/patterns`.
