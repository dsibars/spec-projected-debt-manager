# Reporting Module Presentation

## Components
- **Global Stats Header:** Large display of Net Balance, Total Receivable, and Total Payable.
- **Balance Chart (Simple):** Visual bar comparison between Payable and Receivable.
- **Summary List:** List of People with their net balance.

## Mobile View
- **Dashboard:** Prominent Global Stats at the top.
- **Tabs:** "Summary", "By Person", "By Tag".

## Desktop View
- **Dashboard:** Grid layout with Global Stats and a detailed table of balances by Person.
- **Side Panels:** Breakdown of balances by Groups (from People module).

## Overrides
- Net Balance should be Green if positive, Red if negative.
