# People Module Presentation

## Mobile View
- **People List:** Vertical list of names with optional group badges.
- **Person Detail:** Single column showing contact info and a list of groups.
- **Add/Edit Person:** Full-screen modal with input fields.

## Desktop View
- **Split View:** Left sidebar with People List, right pane with Person Detail.
- **Groups Sidebar:** Quick filters to show people by group.

## Overrides
- Uses `@shared/specs/presentation` for colors and typography.
- Person names in lists should use `Primary` color for better visibility.
